# 🤖 AI Voice Assistant (Nova)

A smart AI voice assistant built using React that can listen to voice commands and respond intelligently.

## 🚀 Features
- 🎤 Voice recognition (Speech-to-Text)
- 🔊 Voice response (Text-to-Speech)
- 💬 Smart command handling
- ⚡ Fast and responsive UI
- 🧠 Personalized assistant (Nova)

## 🛠️ Tech Stack
- React.js
- JavaScript
- Web Speech API
- CSS
